# `packages/core`

Vendor-neutral Aura domain contracts.

Expected contents during Phase 1:

- entity/ID types;
- roles and capabilities;
- request/result schemas;
- validation;
- authorization helpers;
- trust labels;
- error vocabulary;
- moderation/thread state transitions;
- idempotency semantics.

Both web and MCP surfaces should depend on these rules rather than duplicating them.
